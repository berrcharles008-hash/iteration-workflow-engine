# 上下文纪律（定点读）

> 从 SKILL.md 提取。规定**读多少** —— "读什么"由 `startup-protocol.md` 的启动读取顺序规定。
> 经验来源：2026-09-17 token 复盘实测 —— 单会话读入 ≈109K 字符（引擎 ≈37K + 方案/清单/state ≈42K + 源码 ≈30K），
> 且历史文本**每轮重放**，是长迭代 token 膨胀的主因（工单见 `runtime/TOOLING-TODO.md` CTX-2）。
> 加载时机：SKILL.md「★ 上下文纪律」5 行摘要命中本条后按需加载；日常遵守摘要即可。

---

## 一、五条定点读规则

| # | 对象 | 纪律 | 操作方式 |
|:--:|------|------|---------|
| R1 | 规格/计划类 | 先定位后定点读 | `search_content` 找章节/符号 → `read_file offset/limit` 只读命中区间 |
| R2 | 状态文件 | 只读关键区间 | `state.yaml` 只读 `current_phase` / `phase_steps` / `tasks_*`（~50 行）；`ACTIVE` 只读 2 行 |
| R3 | 源码 | 只读待改片段 | 仅在"即将编辑 / 落盘前核对"时读；禁"预读整个类文件"；编辑窗口外不读 |
| R4 | 引擎文件 | 只读当前步骤 | 按当前 step 只加载其声明的文件；禁"预读全套"；SKILL.md 摘要优先于展开细则 |
| R5 | 大产物（>300 行） | 摘要 + 片段 | 要求产出方回传"摘要 + diff 片段"，禁全文回传后由主 Agent 再写一遍 |

**单文件红线**：> 50K 字符的文件禁整读（`read_file` 会直接拒绝或挤爆窗口），一律转 R1 流程。

---

## 二、度量与自检

- **主指标**：单轮 `read_file` 合计 **≤ 500 行**（含并行多文件之和）。
- **例外**（须在回复中注明理由）：跨阶段整段重读、冷启动全量加载、用户明确要求通读。
- **兜底动作**：`read_file` 返回 "File too large" ⇒ **直接**转 `search_content` + `offset/limit`，禁换工具硬读全文。
- **自检语**：定位类读取完成后，用一句话说明"读了哪个区间、为什么不读全文"。

## 三、正例 / 反例（本仓库实证）

| 场景 | 反例（禁） | 正例（行） |
|------|-----------|-----------|
| 查工单状态 | 全文读 `TOOLING-TODO.md`（62K 字符 → 工具直接拒） | `search_content("CTX-2")` 命中行号 → 定点读 110-122 行 |
| 查门禁规则 | 全文读 `gate-protocol.md`（18K，实际只用 §一 + §四） | 只读决策树区间 + 豁免表区间 |
| 查迭代进度 | 全文读 `state.yaml` | 只读 `current_phase` + `tasks_*` |
| 改前端一个方法 | 预读整个 `.vue`（800 行） | `search_content` 定位方法 → 读该段 → 编辑 |

> 反例的代价不是"读了一次"，而是**此后每一轮都要重放这份文本**。

## 四、各阶段应用要点

| 阶段 | 高频大文件 | 定点读法 |
|:--:|------|------|
| 01 | L1/L2/L3 知识库 | 只读与需求相关的 L2 模块章节 |
| 02 | `01-需求记录.md`、知识库 | 按评审项定位，不通读 |

| 07 | 迭代目录全部文档 | 先 `search_content` 汇总事实，再对结论段定点读 |

## 五、边界（防误伤）

本纪律**不适用于**以下场景，禁以"省 token"为由跳过：

1. **安全/门禁相关**：`gate-protocol.md` 决策树、微核（`MEMORY.md` 冷启动段）必须读全并逐字执行。
2. **冷启动必读项**：`startup-protocol.md` Step A-E、`project.manifest.yaml`。
3. **落盘前核对**：编辑前允许读**完整函数/片段**（而非整文件）；编辑中若需确认闭合范围，可读该符号完整定义。
4. **用户明确要求通读**时。

## 六、与其它治理项的关系

- **CTX-1**（Team 产物落盘 `temp/team-output/`）：解决"产物全文回传"的**结构性**浪费；本条（CTX-2）解决"Agent 主动读太多"的**行为**浪费。两者叠加预计长任务 token 下降 40%~60%。
- **微核 / 门禁**：与本条无耦合，互不改变对方行为。
- **回流**：本文件与 SKILL.md 摘要段同步回流源仓库（`D:\sj-skills\iteration-workflow-engine`）。
